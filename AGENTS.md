# AGENTS.md

## Project

This is a personal mini-blog for short discoveries and observations about the Japanese language.

Entries should stay compact and informal. The site is primarily a log of ongoing exploration, not a dictionary, textbook, or comprehensive reference.

At the same time, the accumulated notes should be easy for other people to browse and explore. Prefer lightweight ways of connecting and organizing entries without forcing every observation into a rigid structure.

Keep the project small and simple. Add structure only when the content actually requires it.

## Code

- Optimize for readability and ease of change.
- Use clear, descriptive names.
- Keep functions and components small and focused.
- Prefer simple, explicit solutions over clever abstractions.
- Avoid premature generalization.
- Keep related code close together.
- Remove unused code.
- Follow the existing conventions of the codebase.

## Changes

- Make the smallest clean change that solves the task.
- Avoid unnecessary dependencies.
- Do not change unrelated parts of the project.
- Preserve existing behavior unless the task requires otherwise.

## Verification

Run the relevant formatter, linter, type checks, and tests before finishing.
